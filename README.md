# mailmatch

Open source project for mail automation with chrome extension support.

## Project Structure

This repository is organized as follows:

- **`extension/`**: Chrome Extension (Manifest V3) codebase containing the popup UI, background service workers, and content scripts.
- **`backend/`**: Backend service built with Python and FastAPI to support extension functionality.
- **`docs/`**: Documentation, architecture notes, and setup guides.
